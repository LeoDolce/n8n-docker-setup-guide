# Docker + n8n Setup Guide

Technical documentation for installing, configuring and running n8n locally using Docker on Windows.

## Objective

This repository centralizes installation procedures, operational notes and best practices for local and client-oriented n8n environments.

## Architecture Overview

- Windows 10/11
- Docker Desktop
- n8n Container
- Persistent Docker Volume
- Browser Access

## Documentation Flow

1. Requirements
2. Docker Installation
3. Docker Validation
4. Persistence Volume
5. n8n Container Setup
6. First Access
7. Client Structure
8. Update Process
9. Best Practices
10. Troubleshooting

## Technologies Used

- Docker Desktop
- Docker Volumes
- n8n
- WSL2
- Windows 11

## Final Result

A functional, local and replicable automation environment ready for workflow development and client usage.
